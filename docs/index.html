songforge

Every song on this page was made on a MacBook Air. No cloud, no subscription.

songforge is a local, Suno-style song studio for Apple Silicon. Lyrics plus a style prompt become a full song with vocals, and any recording can be covered in a new genre. It runs YuE2-3B through MLX.

$ uvx songforge

Covers

The source is transcribed to a melody score, then sung in a new style with new or original lyrics. Sources are public-domain melodies rendered as plain piano by a script in the repo, so no recording rights are involved.
